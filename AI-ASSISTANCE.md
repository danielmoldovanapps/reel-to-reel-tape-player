# Development history and AI assistance

The application was developed with substantial AI assistance under Daniel
Moldovan's direction. That assistance covers much of the first-party application
implementation and supporting material, including:

- The HTML/JavaScript deck interface, animation and transport logic.
- The Web Audio tape-speed/pitch engine.
- The Python GTK/WebKit shell, local HTTP backend, artwork/metadata integration,
  file handling and preferences/playlist persistence.
- Package-building scripts, the Snap recipe, tests and project documentation.

The extent is substantial across the first-party codebase; a reliable
line-by-line percentage has not been measured. Human input includes feature
requests, design/behaviour decisions, branding, donation destinations and desktop
testing reported by the project owner. This document does not imply that every
historical implementation detail has been independently audited.

Bundled third-party libraries are upstream components with their own authors,
source and licenses. This disclosure does not claim their code was generated
for this project. See the third-party notices and source directories.

Flathub's requirements, as checked October 21, 2026, require disclosure of known
AI-generated material and prohibit AI-generated or AI-assisted manifests. They
also prohibit AI agents from opening submission pull requests or generating
submission commit messages, descriptions and review interactions. Application
acceptance is discretionary; disclosure does not guarantee acceptance.

Any Flathub packager must independently consult and comply with current policy:
https://docs.flathub.org/docs/for-app-authors/requirements

No Flathub submission has been made as part of preparing this repository.
